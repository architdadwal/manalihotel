# Sugyan Homestay website
Responsive React + Vite website concept for Sugyan Homestay, Haripur, Manali.

## Run locally
```bash
npm install
npm run dev
```
## Build
```bash
npm run build
npm run preview
```
## Vercel
Framework: Vite | Build command: `npm run build` | Output directory: `dist`.
